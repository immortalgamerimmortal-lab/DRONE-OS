# Simulator controls

All controls affect only the local virtual aircraft.

| Key | Action |
|---|---|
| W / S | Forward / backward |
| A / D | Left / right |
| Q / E | Yaw left / right |
| R / F | Climb / descend |

Use the simulator's takeoff and land buttons for stable vertical transitions. Drag to orbit, scroll to zoom, and right-drag to pan. **Follow ON** tracks the drone while preserving camera offset; **Follow OFF** keeps the camera at its current world position. **Recenter** smoothly points the camera at the aircraft.

Keyboard input is cleared when the window loses focus or becomes hidden and is ignored while typing in form fields.
